# Provenance

Minimal Omni source is authored for the independent community project. The
official DSH runtime remains an external pinned dependency. The capability
broker imports official DSH tool APIs and does not copy upstream source files.
The public staging is generated from the local package after path and secret
scans; research and local runtime state are excluded. Vision route gating is a
Minimal Omni fail-closed adaptation; it does not add a second model or router.
