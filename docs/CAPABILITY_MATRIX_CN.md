# Minimal Omni 能力分层矩阵

公开 Developer Preview 分层如下：

- **SUPPORTED / LIVE-TESTED:** Official Minimal brain、`pwsh`、
  `str_replace_editor`、capability broker、Code/LSP、Web fetch、Browser、
  PDF/DOCX/ZIP Documents、Jobs、native Goal、native manual `/compact`、
  session reload continuation、integrated coding、Provider Request Governor、
  `DSH_HOME` Guard、Tool/Turn/watchdog safety、owned cleanup、install/doctor/rollback。
- **EXPERIMENTAL:** XLSX/PPTX model-facing targeting、Goal continuity across
  successful compaction、automatic compaction tuning、optional media metadata/frame。
- **CONDITIONAL:** Vision（route 必须声明 image input）、Web Search（需要配置）、
  authenticated GitHub（需要明确授权）。
- **DEFERRED:** Windows desktop automation、ASR、广义音视频理解、cross-Agent handoff。

不 shipping 稳定的 Minimal Omni `0.68` compaction override；继承 pinned DSH
行为。`deepseek-anthropic / deepseek-v4-pro[1m]` 在 dispatch 前拒绝 inline
image input，因此 Vision 只作 route-conditional。
