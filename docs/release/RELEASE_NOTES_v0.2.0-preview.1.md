# v0.2.0-preview.1 — Minimal Omni Developer Preview

Minimal Omni keeps the official Minimal brain clean and leases bounded Code/LSP,
Web, Browser, PDF/DOCX/ZIP Documents, Jobs, Goal, and runtime-safety
capabilities on demand. The first supported platform is Windows and the
compatibility pin is `dsh-v0.1.2-rc.1` at commit
`a66e4702047846cdaa10c66c9d3df3951f5ea70d`.

XLSX/PPTX model-facing workflows, Goal continuity across successful compaction,
automatic compaction tuning, and optional media metadata/frame extraction are
Experimental. Vision, Web Search, and authenticated GitHub actions are
Conditional. Desktop automation, ASR, broad audio/video semantic understanding,
and cross-Agent handoff/portability are Deferred.

This is a Developer Preview, not a stable or production-certified release.
