# Capabilities

The frozen public contract is maintained in
[CAPABILITY_MATRIX.md](CAPABILITY_MATRIX.md) and
[CAPABILITY_MATRIX_CN.md](CAPABILITY_MATRIX_CN.md).

The short version:

| Tier | Included capabilities |
| --- | --- |
| Supported / live-tested | Minimal brain, pwsh, str_replace_editor, capability-on-demand, Code/LSP, Web fetch, Browser, PDF/DOCX/ZIP, Jobs, native Goal, native manual `/compact`, reload continuation, integrated coding, install/doctor/rollback, and runtime cleanup boundaries |
| Experimental | XLSX/PPTX model-facing workflows, Goal continuity through compaction, automatic compaction tuning, optional media metadata/frame extraction |
| Conditional | Vision, Web Search, authenticated GitHub actions |
| Deferred | Windows desktop automation, ASR, broad audio/video semantics, cross-Agent handoff |

“Supported” means supported for the pinned preview scope, not that every
provider route has identical tools or modalities.
